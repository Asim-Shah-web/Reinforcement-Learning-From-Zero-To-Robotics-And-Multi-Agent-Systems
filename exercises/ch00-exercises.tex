\section*{Exercises}

\begin{enumerate}
  \item \textbf{Conceptual.} In your own words, explain the difference
  between a \emph{state} and an \emph{observation}, using Example D
  (Robotic Arm) as your setting. What might the true state include that a
  camera-based observation would miss?

  \item \textbf{Thought experiment.} Why do you think the book reuses five
  recurring examples instead of introducing a new environment every
  chapter? What would be lost pedagogically if every chapter used a fresh
  example?

  \item \textbf{Notation.} Without looking back at the table, try to write
  down what each of $\state_t$, $\act_t$, $\rew_t$, $\discount$, and
  $\policy(\act \mid \state)$ represents. Then check yourself against
  Section~\ref{sec:notation}.
\end{enumerate}
